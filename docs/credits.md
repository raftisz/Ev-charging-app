# Photo credits

[← back to README](../README.md)

Every station photo in `public/stations/` is a real photograph from
[Wikimedia Commons](https://commons.wikimedia.org/), used under the Creative
Commons licence its author chose. None of them shows Volt Grid or the Bangkok
station it illustrates: they are stand-ins picked to match each station's
setting (indoor car park, roadside stop, garden, night street and so on).

**Changes made to every photo:** cropped to 3:2, resized to 1200 × 800 and
converted to WebP. Photos marked *denoised* also had a light blur (radius
0.8 px) applied before encoding, to keep the file near 200 KB. The changed
files are shared under the same licence as the original; for CC BY-SA photos
that means CC BY-SA, same version.

## Sources tried

Unsplash and Pexels were searched first, but both refused automated
requests (a bot check and HTTP 403), so no photo was taken from them.
Only Commons files licensed CC0, CC BY or CC BY-SA, landscape, without
prominent brand logos, readable number plates or recognisable faces were
used. The airport photo (`suvarnabhumi-airport-hub.webp`) already had its
number plates blurred by the uploader.

If a photo is removed, delete its file and set that station's `imageUrl`
to `NULL`; the app falls back to the station's gradient.
