# English and Thai

Volt Grid ships in English and Thai. Everything a visitor reads — screens,
toasts, validation, API errors, notifications, receipts, page titles and
dates — follows one language setting.

## How the language is chosen

1. The `vg_locale` cookie, set by the EN | ไทย switch (header, sign-in page,
   Settings) and kept for a year.
2. Otherwise the browser's `Accept-Language`: a Thai browser gets Thai on its
   first visit.
3. Otherwise English.

The language is not part of the URL, so every existing link keeps working.
`src/i18n/config.ts` holds the rules; `getLocale()` in `src/i18n/server.ts`
applies them on the server.

## Where things live

| File | What it does |
|---|---|
| `src/i18n/messages/*.ts` | One file per area (`dashboard`, `charging`, `admin`, …). Each keeps the English and Thai side by side in a `defineMessages(en, th)` call. |
| `src/i18n/define.ts` | Types the Thai half against the English one: a missing key, an extra key or a function with different parameters is a compile error. |
| `src/i18n/I18nProvider.tsx` | Client context. `useI18n()` returns `m` (messages), `f` (formatters), `locale` and `setLocale`. |
| `src/i18n/server.ts` | `getI18n()` for server components, layouts and `generateMetadata`. |
| `src/i18n/format.ts` | Dates, times, durations and units per language, always in Bangkok time. |
| `src/i18n/errors.ts` | Translates API error messages and validation issues on their way out. |
| `src/i18n/notifications.ts` | Translates notifications, which are stored in English, when they are shown. |

## Using it

```tsx
const { m, f } = useI18n();
<h1>{m.charging.title}</h1>
<p>{m.charging.stopBody(f.kwh(energy), f.thb(cost))}</p>
```

Messages with values are functions, so word order can differ between the
languages. Formatters cover money (`f.thb`), energy (`f.kwh`), power (`f.kw`),
distance (`f.km`), durations and dates.

## Dates

Dates are assembled from numeric parts and our own month and weekday names
rather than Intl's formatted strings. Node on the server and the visitor's
browser can run different ICU versions that disagree on details such as a
comma after the weekday, and any difference breaks React hydration. Thai long
dates use the Buddhist year (25 ตุลาคม 2569), as Thai readers expect.

## API errors

Errors are thrown in English where they happen, so server code and logs stay
readable. The shared route `handler()` translates them for the visitor:
exact messages through a table, messages carrying values (a wallet ceiling,
an id) through patterns, and Zod's own messages through Zod's Thai locale.

## Adding a message

1. Add the English and Thai text to the relevant file in
   `src/i18n/messages/`. TypeScript will not build until both exist.
2. Use it through `m.<group>.<key>`.
3. A new server error message needs a Thai line in `src/i18n/errors.ts`;
   `npm run test:i18n` reads every message thrown in `src/app/api` and
   `src/server` and fails on any without one.
