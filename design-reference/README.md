# Design references

| File | What it is |
|---|---|
| `evstations-dashboard-concept.jpg` | **Current source of truth for the visual style.** An "EV Charging Station — Dashboard Concept" pin (pinterest.com/pin/19210735903401279). Soft, airy, light-blue dashboard: borderless white cards on a pale blue canvas, large corner radii, diffuse blue-tinted shadows, pastel stat tiles (lilac / amber / mint), capsule pills and segmented controls, geometric sans typography, soft blue area and bar charts. |
| `Volt Grid.dc.html` + `station-data.js`, `support.js`, `image-slot.js`, `ios-frame.jsx`, `map.html` | The original Volt Grid design canvas. Still the source of truth for **information architecture** (which screens exist, what each one shows) and for the seeded station data. Its flat bordered card styling has been superseded by the concept above. |
